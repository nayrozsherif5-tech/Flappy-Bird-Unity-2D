# 🐦 Flappy Bird – Unity 2D

A 2D endless runner game developed using **Unity and C#** as part of a Game Programming project.

The player controls a bird and must navigate through randomly generated pipes while avoiding collisions and achieving the highest possible score.

## 🎮 Game Overview

The game is a simple, cartoon-style 2D endless runner inspired by the classic Flappy Bird gameplay.

- Control a bird using the keyboard.
- Avoid randomly generated obstacles.
- Earn points by passing through pipes.
- Try to achieve the highest score possible!

## ✨ Features

- **Bird Movement:** Control the bird using gravity and jumping mechanics.
- **Random Pipe Generation:** Pipes appear continuously at random heights.
- **Obstacle Movement:** Pipes move from right to left.
- **Cloud System:** Moving clouds create a more dynamic background.
- **Score System:** Earn one point for every successful pipe passage.
- **Collision Detection:** The game ends when the bird hits a pipe or the ground.
- **Game Over Screen:** Displays the Game Over panel when the player loses.
- **Restart Functionality:** Play Again button to restart the game.
- **Welcome Screen:** Includes Play and Exit buttons.
- **Sound Effects:** Five sound effects for different gameplay events.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the downloaded project folder.
5. Open the project in Unity.
6. Open the Welcome Scene and press Play.
